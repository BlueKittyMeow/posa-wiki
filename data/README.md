# data/

Regenerable scrape/analysis dumps, not source; kept out of git.

These are point-in-time outputs of scraper and mining scripts (channel
scrapes, chapter/caption test fixtures, trip/description analysis results)
plus one archived terminal transcript. They can be regenerated by rerunning
the relevant script and are not needed to build or run the app.

## Exceptions: human review decisions (tracked in git)

Three files here are *not* regenerable and are deliberately committed:

- `series_review_decisions.json` — approve/reject per (video, proposed series)
  from `/admin/review/series`. Both the queue and `scripts/assign_series.py`
  read it, so a decided pair is never proposed again.
- `tag_review_dismissed.json` — tags rejected in `/admin/review/tags`.
- `dog_review_dismissed.json` — videos rejected in `/admin/review/dogs`.

Everything else in this directory is a point-in-time script output and stays
out of git.
